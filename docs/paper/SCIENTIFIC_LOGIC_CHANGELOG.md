## 1. 为什么要重写：旧稿的三个结构性问题

旧稿（重写前）是一篇**单数据集案例研究**，其科学逻辑为"平台 + DeepCRISPR + 诚实报告阴性结果"。在整合了三个数据集的完整挖掘结果与外部模型验证产物之后，旧稿暴露出三个结构性问题：

### 问题一：只报告了一个数据集，而第二、第三个数据集的结果已经存在，且结论相反

旧稿的全部性能数字来自 DeepCRISPR。但仓库中已存在两个用**同一套流程**跑完的外部数据集批次：

| 数据集 | 模型数 | 测试 R² 范围 | 结论 |
|---|---|---|---|
| DeepCRISPR | 7 配置 × 64 run | +0.067 … +0.120（中位） | 弱正信号 |
| **Hiranniramol** | 7 | **+0.345 … +0.489** | 强正信号 |
| **Labuhn** | 7 | **−0.725 … −0.049（全部为负）** | **无信号** |

旧稿没有报告后两者。这不只是"补充结果"的问题：**它改变了论文的主张范围**。旧稿可以写"模型学到了可泛化的序列信号（尽管不能跨细胞系）"，而三个数据集并列之后，正确的表述是"**序列可预测性是数据集依赖的，不能假定为可移植的性质**"。这是两个不同强度的科学陈述，前者在证据上不成立。

### 问题二：归因结论完全建立在本文自己的模型族上，缺少独立检验

旧稿的核心正面结论是"多模型归因一致指向 PAM 邻近位置（第 18/20 位）"。但五个模型类共享同一份数据、同一份标签与同一套预处理；它们的一致归因**不能排除共同依赖同一混杂结构**。旧稿没有引入任何外部系统来检验该结论。

仓库中已完备地搭建了独立第三方模型 CRISPRon 的验证链路（输入映射、30-mer 构造、饱和突变、黄金测试等价性证明）。将其接入论文后，"第 18 位重要"这一陈述从*单一模型族内的观察*升级为*跨独立系统（不同训练数据、不同输入编码、不同输出尺度）的可复现观察*。

### 问题三：证据没有分层，导致"能说什么"依赖行文措辞而非方法约束

旧稿在正文中区分了"观察/统计证据/解释"三层，但没有形式化定义，也没有在每处结论上强制标注。其后果是：归因幅值（本不构成统计证据）与统计检验结果混排；模型内部反事实（ISM）与实验证据的边界靠句子里的"不构成因果证据"来维持，而不是靠结构约束。

## 2. 新的科学逻辑：一条五段式证据链

重写后的论文以**多数据集复现 → 多模型外部验证 → 可解释分析 → 反事实扰动 → 生物学假设**为证据链，并围绕三个研究问题组织：

- **RQ1（复现）**：序列可预测性在独立数据集间是否复现？→ §3.2
- **RQ2（外部证实）**：多模型归因指认的序列位置能否被独立外部模型证实？→ §3.6（归因） + §3.9（外部验证）
- **RQ3（可证伪化）**：该位置能否转化为预登记、可证伪的最小扰动假设？→ §3.10（反事实） + §3.11（关联） + §3.12（整合）

**证据链的收敛点**：第 18 位同时获得 E2（实测标签关联）、E3（五类模型归因）、E4（本文模型 ISM + 独立外部模型 CRISPRon）三层**互相独立**的支持，但**不含任何 E5（实验）证据**，因此止步于可证伪假设。这是本文唯一被写成"候选假设"的结论，也是全文最强的计算证据组合。

## 3. 六层证据：新增的方法约束

新增表 `tab10_evidence_layers.tex`（`\label{tab:evidence-layers}`），把证据形式化为六层，并要求全文每处结论标注所属层：

| 层 | 名称 | 回答的问题 | 本文实例 | 不能支持 |
|---|---|---|---|---|
| E1 | 预测证据 | 未见样本上能否预测标签 | 测试集 R²/Pearson/Spearman；跨数据集复现；CRISPRon WT/C18A 评分差 | 因果；机制 |
| E2 | 关联证据 | 标签与可观测属性是否同变 | 第 18 位 C/A 分组实测效率差；GC–效率相关 | 因果；干预效应 |
| E3 | 归因证据 | 模型输出依赖输入的哪些部分 | 线性系数、TreeSHAP、IG、CNN 逐位点归因、注意力 | 统计显著性；生物学重要性 |
| E4 | 反事实证据 | **模型**在输入被扰动后如何响应 | 符号化 ISM；逐位点饱和突变；候选模式破坏 | 真实编辑效率变化 |
| E5 | 实验证据 | 真实实验中扰动是否改变结果 | **本文无** | — |
| E6 | 因果证据 | 干预是否在该体系中导致效应 | **本文不作任何断言** | — |

该分类在本文中实际改变了三处写法（见 §4.5）。

## 5. 数字层面的修正（重要）

重写过程中发现并修正了**三处旧稿数字错误**。这些错误不是笔误，而是口径或实现缺陷，已在论文中如实披露。

### 5.1 数值发散计数：33 → **20**

| | |
|---|---|
| 旧稿 | "Linear Regression 在 192 次运行中有 33 次（17%）R² 数值发散" |
| 实际 | **测试集口径 20 次**（single 6、mixed 6、all 8）；33 是**验证集**口径的数字 |
| 根因 | `deploy/hpc/verify_hpc_rerun.py:165` 用 `list(run_dir.glob("*metrics*.json"))` 取第一个可解析文件，而 glob 的目录顺序会让它在 `*_metrics.json`（测试集）与 `*_validation_metrics.json`（验证集）之间漂移 |
| 修复 | 显式排除 `validation` 文件名，只读测试集指标；并在论文 §3.1 与 §5.3 披露该口径问题 |
| 影响面 | `docs/paper/tables/tab0_data_quality.tex`、`results/tables/audit/ultimate_run_verify_*` |

1. 把位置层级归因的权威统计纳入 `analysis/paper_numbers.py` 的新函数 `attribution_position_stats()`，从 `position_profile_by_model.csv` 与 `cross_model_position_consistency.csv` 计算，落盘到 `authoritative_numbers.json` 的 `attribution_position` 字段；

4. 摘要、结论第 5 条、§3.12 观察 2、收敛表 `tab:convergence` 的 E3 行、图 4 图注全部同步改写；删除"五类模型一致"与"第 18 位进入 top-3"两类表述；
5. `make_assets.py` 中 `tab6_candidates` 的 C1 行由硬编码 `"3/5 models in top-3 positions"` 改为	extbf{从 `cross_model_position_consistency.csv` 动态计算}（现输出 `peak in 17-20 window for 4/5 model classes (minimum 21.9%)`）。

新增 `tests/scientific/test_paper_terminology.py`（49 项），把论文的两条约束固化为断言：**术语纪律**（7 条禁用措辞只允许出现在否定语境；归因幅值不得写成"显著"）与**口径纪律**（发散计数必须为 20；不得残留 `{n//3}` 占位符与 `4/5` 魔数；旧数值 0.529 不得残留；E5 必须标注"本文无"、E6 必须标注"本文不作任何此类断言"）。该测试经负向验证：临时注入违规后立即失败。
