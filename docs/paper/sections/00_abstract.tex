基因编辑效率的机器学习预测已取得进展，但预测精度的提升并未同步带来对影响因素的可靠解释；更关键的是，若训练与测试之间存在同源序列，跨条件的性能估计会被系统性高估，而这类问题在只报告精度时往往不可见。本研究构建了一个把质量控制、数据划分与泄漏审计、特征工程、受控多模型实验、模型归因、统计推断、环境因素析因分析、序列模式挖掘、细胞背景比较与跨模型证据整合组织为统一流程的科学发现平台，并以 DeepCRISPR 公开数据（4 个细胞系、16\,749 条 23\,nt 靶序列、1\,344 次受控训练运行）开展案例研究。平台使用 Linear Regression、XGBoost、多层感知机（MLP）、双分支卷积神经网络（CNN，序列卷积核 3/5/7）与 Transformer 五类具有不同归纳偏置的模型，并严格区分预测效应（$\Delta R^{2}$）、模型归因、稳健性与统计证据。

本文最重要的方法学结果来自对自身历史批次的审计与整改：早期批次按记录随机划分，且留一细胞系（LOCO）分支未剔除留出系同源序列，导致同一 sgRNA 序列可同时进入训练与测试两侧。在按"序列及其反向互补构成同一身份类"重新划分并完整重跑 1\,344 次实验后，\emph{mixed} 划分的中位 $R^{2}$ 由 0.118 降至 0.073，LOCO 由 $+0.036$ 降至 $-0.008$，而单细胞系划分基本不变（0.070 $\rightarrow$ 0.081）。这一差异化变化表明：此前较高的跨细胞系性能至少有相当部分由跨细胞系的同源序列重复支撑。

在此基础上，本文按证据强度报告：（i）数据可信度层面，1\,344/1\,344 次运行的 train$\cap$test 序列重叠与反向互补重叠均为 0，划分摘要逐条复核一致，全批运行于同一数据、代码与数值栈之上；（ii）预测能力有限且跨细胞系泛化失败——细胞系内中位 $R^{2}$ 为 0.067--0.120，真实 LOCO 的 7 个模型配置全部落在 $-0.112$ 至 $+0.010$，并呈显著细胞系异质性（HEK293T 最低，$R^{2}=-0.266$）；（iii）跨模型归因在\textbf{位置层级}一致指向 PAM 邻近位置（跨模型平均谱峰值第 18 位；XGBoost 与 MLP 分别有 91.7\% 与 86.5\% 的运行把最高归因位置落在 17--20 窗口），但在粗粒度区域汇总下仅 XGBoost 与 Transformer 的最高区域为 PAM 邻近种子区；（iv）四个表观环境因子（CTCF、DNase、H3K4me3、RRBS）的增量预测效应为 $3\times10^{-4}$--$1.5\times10^{-3}$，比预设门槛 0.01 低 1--2 个数量级，跨模型区间全部跨 0，区组析因方差分析主效应 $p=0.975$--$0.9996$，四者在证据框架中均为 \textbf{Inconclusive}；（v）更宽的 CNN 感受野带来小幅但可复现的提升（$k=7$ 相对 $k=3$：$+0.0169$，区间 $+0.0077$--$+0.0257$），且候选模式长度不随核大小改变，说明卷积核是感受野参数而非模式长度。

平台的科学性不体现在"所有分析均得到阳性结果"，而体现在统一、可追溯的框架中区分稳定证据、模型特异性现象、上下文依赖现象与不确定结果，并据此输出可检验的候选假设（如第 18 位碱基替换、PAM 邻近候选模式扰动）。本研究属于**计算案例研究（computational case study）**：已完成受控计算验证、统计推断与候选因素优先级排序，尚未开展湿实验验证；平台输出的是待验证假设，而非已确认的生物学机制，也不作任何因果断言。
