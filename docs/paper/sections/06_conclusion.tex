\section{结论}
\label{sec:conclusion}

本文以"多数据集复现 $\rightarrow$ 多模型外部验证 $\rightarrow$ 可解释分析 $\rightarrow$ 反事实扰动 $\rightarrow$ 生物学假设"为证据链，在严格无泄漏、序列级不相交的评估下重新回答了"sgRNA 效率的序列信号有多可信、哪个位置值得实验检验"这两个问题。全文结论按六层证据（E1--E6，表~\ref{tab:evidence-layers}）组织，每条均标注其强度与边界。

\begin{enumerate}
\item \textbf{数据可信度（E1 前提，穷举核对，强）}：1\,344 次运行的实验矩阵完整，1\,344/1\,344 的 train$\cap$test 序列重叠与反向互补重叠为 0，划分摘要逐条复核一致，全批运行于同一数据、代码与数值栈之上（表~\ref{tab:dataquality}）。按测试集口径，数值发散 run 为 20 次（全部为 Linear Regression）。
\item \textbf{序列可预测性是数据集依赖的，不可移植（E1，强）}：在完全相同的特征、模型与评估流程下，DeepCRISPR \emph{single} 划分的 7 个配置中位 $R^{2}$ 为 $0.067$--$0.120$，Hiranniramol 为 $0.345$--$0.489$（Transformer 最高，$R^{2}=0.489$，Pearson $=0.709$），而 Labuhn 的 7 个配置\textbf{全部为负}（$-0.725$ 至 $-0.050$）。与官方划分无关的全数据 5 折 CV 复核给出同向结论：Hiranniramol $+0.389$（零分布 $-0.467\pm0.038$），Labuhn $-0.144$（零分布 $-0.287\pm0.050$）。Labuhn 的失败机制可诊断为\emph{预测坍缩}：6/7 个配置的预测标准差与标签标准差之比仅 $0.03$--$0.37$。\textbf{本文据此不把"序列信号存在"写作普适结论。}
\item \textbf{跨细胞系迁移失败（E1，强）}：真实 LOCO 划分下 7 个配置的中位 $R^{2}$ 全部落在 $-0.027$ 至 $+0.010$，与均值基线不可区分；按留出系展开异质性大（HEK293T 最低，$R^{2}=-0.266$）。该结果同时混杂训练池缩减（$n_{\text{train}}$ 1\,453--12\,313），故只报告"不可区分"。
\item \textbf{环境通道未获得增量预测证据（E1，强）}：CTCF、DNase、H3K4me3、RRBS 的 $|\overline{\Delta R^{2}}|$ 为 $3.2\times10^{-4}$--$1.5\times10^{-3}$，比预设门槛 $0.01$ 低 1--2 个数量级；跨模型区间全部跨 0；区组析因方差分析主效应 $p=0.975$--$0.9996$。四者均为 \textbf{Inconclusive}。该结论是\emph{未检出}，不是\emph{无作用}，且仅来自 DeepCRISPR（两个外部数据集无表观通道）。
\item \textbf{四个非模型类的位置归因指向 PAM 邻近窗口，线性模型例外；区域层级仅部分一致（E3，中）}：XGBoost、CNN、MLP、Transformer 的逐上下文归因峰值落在第 17--20 位窗口的比例分别为 100.0\%、96.9\%、90.6\%、65.6\%，其单模型平均谱峰值分别位于第 18、20、18、19 位；\textbf{线性模型仅 21.9\%，峰值在第 1 位}。把线性模型纳入等权平均后，跨模型平均谱峰值是第 1 位（0.0864）而非第 18 位（0.0799）；剔除线性模型后峰值才是第 18 位（0.0878）。按粗粒度区域汇总时只有 2/5 的最高区域为 PAM 邻近种子区。\textbf{归因幅值不构成统计显著性证据。}
\item \textbf{独立外部模型验证（E4，中）}：按预登记规则选出的 8 条第 18 位为 C 的 WT 序列上，本文 7 个模型与独立第三方模型 CRISPRon 对 C$\rightarrow$A 扰动的方向\textbf{在 7/8 条上一致}（幅度相关 $r=0.629$、$\rho=0.476$，$n=8$）；CRISPRon 侧 7/8 条为负向（平均 $\Delta=-12.43$）。唯一分歧样本 WT08 被保留。
\item \textbf{无位置预设的反事实扰动（E4，中）}：对 8 条 WT 做全部 552 条单碱基替换的饱和 in-silico 突变（48 条破坏 PAM 被排除），第 18 位按平均 $|\Delta|$ \textbf{排名 1/21}（12.86，第 2 名为 7.68），逐序列看 7/8 条排第 1；第 18 位 C$\rightarrow$A 平均变化 $-12.425$，其余位置平均仅 $+0.144$。
\item \textbf{观测性关联独立支持同向结论，但具细胞背景依赖（E2，中）}：第 18 位 C 减 A 的实测平均效率差为 HCT116 $+0.090$、HeLa $+0.092$、HL60 $+0.027$、\textbf{HEK293T $-0.015$（方向反转）}。作为独立对照，GC–效率相关在 Hiranniramol 上为 $r=+0.262$（$p<10^{-4}$）、在 Labuhn 上为 $r=+0.094$（$p=0.054$），与 RQ1 结论一致。
\item \textbf{泄漏整改的如实报告（E1 方法学，中）}：排除跨细胞系同源序列后，\emph{mixed} 中位 $R^{2}$ 由 0.118 降至 0.073，LOCO 由 $+0.036$ 降至 $-0.008$，而 \emph{single} 划分基本不变（0.070 $\rightarrow$ 0.081）。本文把该下降作为主要发现之一报告，而不是需要解释掉的异常。
\item \textbf{可证伪的候选假设（E4，弱—中，无 E5）}：本文输出一个生物学假设——\emph{第 18 位碱基身份与编辑效率关联，C$\rightarrow$A 降低效率，效应大小依赖细胞背景}——及其最小扰动验证方案（保持其余 22\,nt 不变，仅替换第 18 位并做配对测定）。该假设同时获得 E2、E3、E4 三层\emph{互相独立}的支持，但\textbf{不含任何 E5 证据，因此不构成因果结论}。
\end{enumerate}

综上，本文的贡献不在于报告一个高精度预测器，也不在于证明某个序列位置具有因果作用，而在于展示一套能把"数据是否可信""结论能否复现""归因能否被外部系统证实""假设能否被实验证伪"四件事分开回答、且每件事都有明确证据层级的流程。按其输出，本文对领域最直接的提醒是：\textbf{在引用任何 sgRNA 效率预测性能之前，应当先问它在多少个独立数据集上被复现过。}
