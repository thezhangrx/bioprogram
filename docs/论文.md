# 面向基因编辑系统的细胞环境感知型核酸工具智能设计与影响因素发现平台

## 摘要

基因编辑技术的发展使基于机器学习的核酸工具设计逐渐由经验筛选转向数据驱动的效率预测与候选优化。以 CRISPR-Cas 系统为代表的基因编辑工具可以利用核酸序列及细胞环境信息建立复杂的预测模型，从而辅助高效编辑位点的识别。然而，随着模型由线性模型逐步发展到树模型、深度神经网络及注意力模型，模型所学习的序列模式、环境依赖关系以及细胞类型差异也更加难以直接从预测结果中解释。DeepCRISPR 等研究已经表明，序列与细胞特异性表观遗传信息可以共同用于 sgRNA 编辑效率建模，并进一步考察模型在不同细胞类型之间的泛化能力。([Springer][1])

针对预测模型与科学因素发现之间的鸿沟，本研究构建了一个面向基因编辑系统的细胞环境感知型核酸工具智能设计与影响因素发现平台。平台以科研人员已有的实验测量数据为主要输入，将数据质量控制、特征工程、受控机器学习实验、模型特异性可解释分析、统计效应分析以及跨模型证据整合组织为统一流程。平台采用 Linear Regression、XGBoost、MLP、双通道 CNN 和 Transformer 五类具有不同数学归纳偏置的模型，从线性主效应、树结构非线性交互、一般非线性特征组合、局部序列模式以及跨位置信息交互等多个角度对相同实验数据进行分析。对于不同模型，平台进一步采用回归参数、TreeSHAP、Integrated Gradients、In Silico Mutagenesis 等相应解释方法，区分模型归因、预测增量、统计证据与稳定性证据，避免将不同性质的指标简单归一为“显著性”。

在序列因素分析方面，平台进一步以深度模型的序列归因为基础，将高归因序列片段提取、聚类、共识模式构建和 motif 验证组织为候选序列模式发现流程；在环境因素分析方面，平台通过 sequence-only baseline 与加入环境因素后的性能增量比较，评估细胞环境信息所提供的额外预测贡献，并结合重复实验、置信区间及因素交互分析评估其稳定性；在细胞系层面，平台进一步考察相同因素在不同细胞环境中的效应异质性。最终，平台将预测效应、模型归因、统计证据、稳健性以及跨模型和跨细胞系的一致性整合为统一证据体系，并形成可追溯的候选因素及生物学假设。

本文以 DeepCRISPR 数据作为案例数据集，对平台的数据输入、特征工程、模型训练和分析流程进行展示。案例结果主要用于验证平台的完整运行能力和影响因素发现流程，而非作为平台适用性的唯一证明。平台的最终目标是从科研人员已经获得的实验数据中进一步挖掘可解释的序列、环境和细胞背景信息，并为后续核酸工具设计和实验验证提供候选依据。

# 1 引言

## 1.1 基因编辑工具设计由预测走向数据驱动

CRISPR-Cas 系统的广泛应用使 sgRNA 设计成为基因编辑实验中的重要计算问题。对于给定目标位点，不同 sgRNA 往往表现出不同的编辑效率，因此如何在实验前筛选具有较高潜在活性的核酸序列，一直是计算基因编辑领域的重要研究问题。传统的核酸工具设计主要依赖经验规则、序列特征及有限的人工统计模型，而机器学习方法的发展使得研究者能够直接从大规模实验数据中学习序列与编辑表型之间的关系。

随后发展的深度学习方法进一步增强了对复杂序列关系的建模能力。DeepBind 等研究证明，深度学习能够直接从 DNA 和 RNA 序列实验数据中学习局部序列特异性，并能够进一步生成位置特异性的解释结果。([PubMed][2]) 在基因组调控问题中，Basset 等工作进一步展示了卷积神经网络可以从 DNA 序列中学习与功能活性相关的局部序列模式，并将卷积滤波器与序列 motif 联系起来。([Genome][3])

在 CRISPR 场景中，DeepCRISPR 将这一思路进一步扩展到 sgRNA 编辑效率和脱靶预测问题，并利用序列和细胞特异性表观遗传信息建立统一的编码与深度学习框架。该研究使用 CTCF、H3K4me3、DNase 和 RRBS 等环境信息，并对不同细胞类型中的模型泛化能力进行了分析。([Springer][1])

这些研究说明，机器学习不仅能够用于提高编辑效率预测能力，也为从复杂生物数据中发现影响编辑结果的潜在因素提供了新的可能。

## 1.2 从“预测结果”到“影响因素发现”

然而，预测能力的提高并不意味着研究者能够直接理解模型究竟依据哪些生物学因素作出判断。

线性模型可以直接给出参数方向和统计证据，但其表达能力受到模型形式限制；树模型能够建模非线性关系及特征交互，但传统 Gain、Weight 和 Cover 等重要性指标并不能直接提供具有明确方向的局部效应；深度模型则能够从序列中学习更复杂的表示，但模型内部的高维表示往往难以直接解释。

因此，在机器学习应用于生命科学的过程中，预测模型和科学解释之间形成了新的方法学需求。SHAP 从 Shapley value 出发建立加性特征归因框架，为解释复杂模型提供了统一的理论基础；Integrated Gradients 则通过 Sensitivity 和 Implementation Invariance 两项公理定义深度神经网络的输入归因方法。([Proceedings of Machine Learning Research][4])

对于 DNA 序列问题而言，可解释性的意义不仅在于回答“哪个特征重要”，还在于进一步回答：

> 哪些序列位置和局部模式可能与编辑效率相关？

> 哪些环境因素在序列信息之外提供了额外预测信息？

> 同一个因素在不同细胞环境下是否具有不同的贡献？

> 不同模型是否独立地支持同一个候选因素？

因此，仅比较模型 R² 或其他预测指标已经无法完整回答上述问题。

## 1.3 序列模式与 motif 是重要的解释对象

DNA 序列中许多生物学功能由短序列模式及其组合所决定。深度学习尤其是 CNN 已被广泛用于从 DNA 序列中学习 motif-like patterns。Basset 的卷积滤波器直接作用于 one-hot DNA 序列，并通过卷积与后续层学习局部序列模式；相关研究显示，卷积模型可以提取具有生物学意义的序列模式。([Genome][3]) DeepBind 同样展示了从深度模型中恢复序列特异性以及基于 mutation map 解释具体序列变化的能力。([PubMed][2])

然而，将深度模型的 attribution 直接等同于 motif 本身仍存在明显问题。单个高归因位置并不必然构成完整 motif，模型卷积核大小也不能直接等同于生物学 motif 长度。因此，本研究的平台进一步将序列 attribution、局部高归因片段提取、序列聚类、共识模式构建和 motif enrichment 组织为连续分析过程，使模型解释从“重要位置”进一步延伸到“候选序列模式”。

## 1.4 研究目标

基于上述问题，本研究设计并实现一个以科研人员已有实验数据为入口的基因编辑影响因素发现平台。平台并不将目标限定为构建一个新的单一预测器，而是希望建立：

> **从实验数据 → 预测模型 → 模型解释 → 统计证据 → 因素发现 → 生物学假设的完整计算链条。**

平台重点关注三个问题：

1. **序列因素**：哪些序列位置及候选 motif 与编辑效率相关？
2. **环境因素**：细胞表观遗传环境是否能够在序列基础上提供额外的预测信息？
3. **细胞背景**：同一因素在不同 cell-line context 中是否表现出稳定或异质性的贡献？

在这一框架下，预测模型本身是影响因素发现的工具，而不是最终科学结论。

# 2 平台架构与科学发现流程

## 2.1 平台总体设计

本平台将数据处理、模型训练和科学分析划分为相互独立但通过标准化 artifact 相连接的多个模块：

```text
科研人员已有实验数据
        ↓
数据质量控制
        ↓
数据映射与特征配置
        ↓
特征工程
        ↓
受控机器学习实验
        ↓
预测结果与模型解释
        ↓
环境因素分析
        ↓
序列归因与 motif 分析
        ↓
细胞系异质性分析
        ↓
统计证据与跨模型证据整合
        ↓
候选影响因素
        ↓
生物学机制假设
        ↓
后续核酸工具设计
```

平台中的各分析模块均以结构化结果文件作为接口，从而使数据质量控制、模型训练和后续统计分析能够独立运行。训练系统可以在本地或高性能计算平台中独立执行，而分析模块在获得训练结果后进行下游处理。

这一架构的核心并不是让所有模型使用相同的算法，而是让不同模型成为对同一数据问题的不同数学观察视角。

---

## 2.2 多模型分析框架

平台目前采用五类主要模型：

| 模型                | 主要建模视角      | 主要解释方法                          |
| ----------------- | ----------- | ------------------------------- |
| Linear Regression | 线性主效应       | Coefficient、SE、p、FDR            |
| XGBoost           | 非线性树结构与特征交互 | Gain、Weight、Cover、TreeSHAP      |
| MLP               | 一般非线性特征组合   | Integrated Gradients、SmoothGrad |
| CNN               | 局部序列模式与局部交互 | IG、ISM                          |
| Transformer       | 跨位置信息交互     | Attention、IG（若 उपलब्ध）          |

这种设计并不意味着五个模型在统计意义上完全等价，而是利用不同模型的归纳偏置形成互补证据。

# 3 数据与生物学输入

## 3.1 数据输入与细胞环境信息

平台面向科研人员已有的基因编辑实验数据设计。标准输入至少需要包含：

* 核酸序列；
* 编辑效率或其他待预测表型；
* 样本所属 cell line；
* 与目标位点相关的环境信息。

平台的环境信息并不限定于固定的四种表观遗传特征。以当前 DeepCRISPR 案例为例，使用 CTCF、DNase、H3K4me3 和 RRBS 作为细胞环境特征。DeepCRISPR 原始工作将 DNA nucleotide channels 与上述 epigenetic channels 共同构造成多通道区域表示，并明确指出该表示可以在提供所需环境信息的情况下扩展到其他细胞类型。([Springer][1])

因此，本平台将环境特征抽象为 schema，而不是将当前四种环境因素固化为平台唯一输入。

---

## 3.2 DeepCRISPR 案例数据

本文以 DeepCRISPR 相关公开数据作为平台案例数据。

DeepCRISPR 研究使用约 15,000 条具有已知 knockout efficacy 的 sgRNA 数据，并涉及 HCT116、HEK293T、HeLa 和 HL60 等细胞类型，同时进一步研究了 leave-one-cell-type-out 条件下的跨细胞类型泛化能力。([Springer][1])

本文案例使用的数据来源、具体文件、样本数量以及训练集/测试集对应关系将在实验部分按照实际下载和处理结果记录。对于没有经过当前实验流程核验的数字，不在方法部分预先指定。

# 4 平台方法学

## 4.1 数据质量控制

平台首先对用户输入数据执行数据质量控制，而不是直接将原始数据送入模型。

质量控制包括：

* 样本数量和 cell-line 分布；
* 编辑效率分布；
* sequence 长度一致性；
* 非标准碱基与 ambiguous bases；
* GC content；
* environment completeness；
* 重复数据；
* 潜在异常值；
* 数据分布及变量相关性等。

质量控制的主要目的不是自动删除所有异常样本，而是识别可能影响后续分析的结构性问题，并通过结构化 `qc_summary` 将问题传递给后续流程。

特别地，环境信息缺失和真实的生物学零值必须区分。当前版本平台主要负责识别并报告数据缺失问题，而不会在未经用户配置的情况下将缺失环境信息自动解释为零值。

对于 ambiguous nucleotide，例如 `N`，平台首先记录异常字符及受影响样本，由后续工作流根据用户配置决定具体处理策略，而不是由 QC 模块擅自修改原始数据。

---

## 4.2 特征工程与数据表示

### 4.2.1 序列表示

对于 DNA 序列，平台采用位置 × 特征的矩阵形式构造模型输入。

DeepCRISPR 原始编码将 A、C、G、T 四种核苷酸分别编码为独立通道，并将各表观遗传变量作为额外通道，形成多通道区域表示。([Springer][1])

在本平台中，为适配不同模型的数学性质，对 sequence encoding 采用模型相关的表示方法。

对于 Linear Regression，在包含截距项的情况下：

$$
A_i+C_i+G_i+T_i=1
$$

因此同时使用四个完整 one-hot 变量会导致完全共线性。平台可将其中一个碱基作为 reference category，例如以 T 为参考类别，显式表示 A、C、G 相对于 T 的差异。这并不意味着 T 被从生物学意义上删除，也不意味着 T 的贡献为零；它只表示 T 是线性参数化中的参考类别。

对于 CNN、MLP 和 Transformer 等非线性模型，则可以保留完整的 A/C/G/T 表示，从而避免将 reference-category encoding 的统计约束引入序列模式学习，并有利于后续 nucleotide-level attribution 和 mutation analysis。DNA 序列深度学习研究中使用四通道 A/C/G/T one-hot 编码是常见做法，例如 Basset 明确采用四行 binary variables 对应 A、C、G、T。([Genome][3])

因此：

> **“Linear Regression 不显式编码 T”是参数可识别性处理，而不是认为 T 没有生物学信息。**

---

### 4.2.2 环境表示

以 DeepCRISPR 案例为例，环境特征包括：

$$
\text{CTCF},\ \text{DNase},\ \text{H3K4me3},\ \text{RRBS}
$$

平台保持统一的 feature schema，使不同环境组合能够在同一实验框架内进行比较。

---

### 4.2.3 重复数据与数据泄漏

为了降低相同观测进入不同数据划分所造成的数据泄漏风险，特征工程阶段对完全重复记录进行识别和处理。

这一过程的目的并不是人为扩大数据差异，而是确保训练、验证和测试数据之间具有明确的数据边界。

---

### 4.2.4 特征与样本元数据

除了保存模型使用的数值矩阵外，平台同时保存 feature schema 和 sample metadata，用于建立：

```text
模型输入特征
        ↕
原始样本
        ↕
cell line
        ↕
sequence position
        ↕
feature identity
```

之间的映射关系。

这样可以在模型解释阶段将某一个 attribution 结果重新对应到具体序列位置、环境因素和原始样本，从而支持后续统计分析、motif discovery 和可视化。

# 5 数据划分与实验设计

平台针对不同科学问题采用不同的数据划分策略。

### Single-cell-line analysis

在单一 cell line 内进行训练、验证和测试，用于观察模型能否学习该细胞环境中的序列—表型关系。

### Cross-cell-line generalization

采用 leave-one-cell-line-out 思路，将一个 cell line 完全作为 held-out context，训练数据来自其他 cell lines，用于评估模型所学规律能否迁移至未参与训练的细胞环境。

DeepCRISPR 原研究本身也采用 leave-one-cell-type-out 方式考察新 cell type 的泛化能力，并比较含和不含 cell-specific epigenetic features 的模型。([Springer][1])

### Mixed analysis

将不同 cell lines 合并后进行统一建模，用于获得总体层面的模型行为及证据。

对于包含随机种子的实验，种子重复用于评估计算过程稳定性；它们不被解释为独立的生物学重复。

# 6 机器学习模型与数学基础

## 6.1 Linear Regression

线性回归作为平台的统计解释基准模型，其基本形式为：

$$
\hat{y}
=
\beta_0+\sum_{j=1}^{p}\beta_jx_j
$$

通过最小化残差平方和：

$$
\min_{\beta}\|X\beta-y\|_2^2
$$

获得模型参数。([Scikit-learn][5])

在线性模型中，\(\beta_j\) 可以直接表示特征与目标之间的条件线性关系，因此适合作为平台中最直接的效应方向和参数统计依据。

当设计矩阵存在秩亏或严重共线性时，平台采用伪逆等数值方法求解线性系统。这里需要强调，伪逆的作用是提高数值求解对秩亏/非满秩矩阵的适应性，而并非简单针对“稀疏矩阵”。

---

## 6.2 XGBoost

XGBoost 作为树模型代表，用于补充线性模型无法充分描述的非线性关系和特征交互。

与线性模型相比，树模型可以通过递归划分特征空间表达非线性关系，并能够利用树结构组合不同变量。

本平台同时保留：

* Gain；
* Weight；
* Cover；
* TreeSHAP。

其中前三者是树模型内部的重要性度量，而 TreeSHAP 则进一步提供样本级的加性归因信息。

因此，XGBoost 在平台中承担的是：

> **非线性表格特征建模 + 可解释树模型归因**

的角色，而不仅是一个性能基准模型。

---

## 6.3 MLP

MLP 用于建立不显式利用序列局部空间结构的非线性模型：

$$
h^{(l+1)}
=
\sigma(W^{(l)}h^{(l)}+b^{(l)})
$$

其作用是判断不同序列和环境特征的非线性组合是否能够形成线性模型无法表达的预测关系。

与 CNN 不同，MLP 不显式假设相邻核苷酸构成局部模式，因此其解释结果可以作为一种“非结构化非线性模型”的对照。

---

## 6.4 双通道 CNN

CNN 是本平台中进行序列模式分析的重要模型之一。

平台采用 sequence branch 与 environment branch 的双通道设计：

```text
Sequence input
      ↓
Sequence branch

Environment input
      ↓
Environment branch

      ↓
Feature fusion
      ↓
Prediction
```

这样设计的目的，是避免将长度和语义不同的序列信息与环境信息简单展平到同一个特征空间中，同时保留序列局部结构与环境变量各自的表示方式。

CNN 使用多个序列卷积核尺度，例如 3、5、7，用于测试不同 receptive field 对局部序列关系建模的能力。

这里的卷积核大小不被直接解释为生物学 motif 长度。相关 DNA CNN 研究表明，卷积核能够从 one-hot 序列中学习局部 pattern，而多尺度卷积也被用于捕获不同长度的 motif-like features。([Genome][3])

因此，本平台的 3/5/7 kernel 实验用于比较不同局部感受野，而 motif length 则由后续 motif discovery 独立确定。

---

## 6.5 Transformer

Transformer 利用 self-attention 建立不同序列位置之间的信息交互，其核心机制与 CNN 的局部卷积不同。Transformer 原始工作提出了完全基于 attention 的序列建模结构。([NIPS 论文集][6])

在本平台中，Transformer 作为一种不同于局部卷积的序列建模视角，用于补充对跨位置依赖和非局部关系的建模。

其作用并不是简单替代 CNN，而是提供一种独立的模型归纳偏置，使后续证据整合能够比较：

```text
局部模式证据
vs.
跨位置交互证据
```

---

# 7 模型解释、统计证据与稳健性

平台不将所有“重要性指标”统称为统计显著性，而将其划分为三个层次：

### Effect

表示效应大小和方向，例如：

$$
\Delta R^2
$$

或线性回归系数。

### Attribution / Importance

表示模型对特征的依赖程度，例如：

* TreeSHAP；
* Integrated Gradients；
* ISM。

### Statistical evidence

来自具有明确统计假设的检验，例如：

* regression p-value；
* FDR；
* permutation test；
* ANOVA；
* motif enrichment。

这种区分对于跨模型证据整合是必要的，因为 SHAP、IG 和 ISM 本身并不是传统意义上的 p-value。

---

## 7.1 Linear Regression

线性模型中的参数：

$$
t_j=
\frac{\hat{\beta}_j}{SE(\hat{\beta}_j)}
$$

可以进一步计算 p-value，并进行 Benjamini–Hochberg FDR 校正。

因此，在当前平台中，Linear Regression 是最直接的经典统计证据来源之一。

---

## 7.2 SHAP

SHAP 基于 Shapley value 理论，为模型预测提供加性 feature attribution。([Proceedings of Machine Learning Research][4])

在本平台中：

$$
\phi_j(x)
$$

表示特征 \(j\) 对样本 \(x\) 的局部归因。

同时可以使用：

$$
\frac{|\operatorname{mean}(\phi_j)|}{SD(\phi_j)}
$$

构造 attribution SNR，用于评估归因结果的相对稳定性。

但是：

> **SHAP-SNR 不被解释为统计显著性。**

---

## 7.3 Integrated Gradients

Integrated Gradients 沿输入与参考输入之间的路径积分梯度：

$$
IG_i(x)
=
(x_i-x_i')
\int_0^1
\frac{\partial F(x'+\alpha(x-x'))}
{\partial x_i}
d\alpha
$$

该方法的设计基于 Sensitivity 和 Implementation Invariance 两项公理。([Proceedings of Machine Learning Research][4])

平台将其应用于 MLP、CNN，以及当前实现支持的 Transformer 序列归因。

---

## 7.4 In Silico Mutagenesis

对于 CNN，平台进一步使用 ISM 分析单核苷酸替换造成的预测变化。

对于位置 \(i\) 的原始碱基 \(b\) 替换为 \(b'\)：

$$
\Delta F_{i,b\rightarrow b'}
=
F(x_{i\leftarrow b'})
-
F(x)
$$

因此 ISM 与 IG 的含义不同：

* IG：当前序列状态对模型输出的 attribution；
* ISM：对当前 nucleotide 进行 counterfactual mutation 后的预测变化。

这使得 ISM 更适合进一步连接到 nucleotide-level effect 和 motif discovery。类似的 mutation map 思路已经用于 DNA sequence deep learning 的解释研究。([PubMed][2])

---

# 8 环境因素分析

## 8.1 Sequence-only baseline

为了判断表观环境信息是否产生额外预测价值，平台首先建立 sequence-only baseline。

对于环境集合 \(S\)，新增因素 \(e\) 后定义条件增量：

$$
\Delta R^2_{e|S}
=
R^2(S+e)-R^2(S)
$$

该指标表示：

> 在已有环境信息 \(S\) 的基础上增加因素 \(e\) 后，预测解释能力发生了多少变化。

因此：

$$
\Delta R^2>0
$$

表示新增环境因素提高了模型的预测解释能力；

$$
\Delta R^2<0
$$

表示其加入后未改善当前模型的测试性能。

这里的“贡献”应理解为**预测增量贡献**，而非因果效应。

---

## 8.2 Paired evaluation

为了避免加入环境因素后样本组成发生变化而产生混杂，baseline 和 expanded model 应尽可能在同一 eligible cohort、相同目标值和相同测试划分上进行比较。

这是平台环境因素分析中的重要原则。

---

## 8.3 Factorial design

对于四个环境因素：

$$
2^4=16
$$

种组合形成完整 factorial design。

因此平台可以进一步分析：

* environment main effects；
* pairwise interactions；
* conditional effects。

在后续完整统计模块中，可进一步采用 factorial ANOVA 对主效应和交互项进行正式统计检验；当相应分析未启用或数据条件不足时，则不生成虚假的统计结果。

---

# 9 序列 Motif 发现

平台中的 motif discovery 不要求五种模型都承担相同任务。

主要候选来源为：

> **CNN 和具有兼容序列 attribution 的 Transformer。**

MLP 的 attribution 可作为辅助证据，但不作为主要 motif extractor。

Motif discovery 的总体流程为：

$$
\text{Attribution}
\rightarrow
\text{Seqlet}
\rightarrow
\text{Clustering}
\rightarrow
\text{Consensus}
\rightarrow
\text{Enrichment}
\rightarrow
\text{Validation}
$$

其中：

1. 根据高 attribution 区域提取局部 seqlets；
2. 区分正向与负向 attribution；
3. 根据序列和 attribution pattern 聚类；
4. 形成 consensus sequence；
5. 使用 PFM/PWM 和 sequence logo 描述 motif；
6. 对候选 motif 进行 enrichment analysis；
7. 根据模型、seed 和 cell-line 等条件评估稳定性。

CNN 从 DNA sequence 中学习局部 motif-like patterns 的能力已有较多研究基础。Basset 明确指出第一层卷积滤波器作用于 DNA one-hot 输入，其功能与 motif-like pattern detection 有关；DeepBind 也能够从训练数据中恢复序列特异性。([Genome][3])

因此，本平台将 CNN/Transformer attribution 进一步组织成 motif discovery pipeline，而不将卷积核大小直接等同于 motif 长度。

---

# 10 Cell-line Context Analysis

相同序列或环境因素的效应可能随细胞背景改变。

因此平台不只比较不同 cell line 的模型预测性能，而进一步分析：

$$
E_{f,c}
$$

即：

> feature \(f\) 在 cell line \(c\) 中的效应。

平台重点考察：

* effect magnitude；
* effect direction；
* confidence interval；
* cross-cell-line consistency；
* context dependence。

根据这些证据，可以将观察结果区分为：

```text
Context-consistent
Context-dependent
Context-conflicting
Uncertain
```

其中：

> “Context-dependent” 表示效应程度与细胞背景存在差异，“Context-conflicting” 则表示方向出现明显不一致。

二者均不直接等价于不同的生物学机制。

---

# 11 跨模型证据整合

平台最终不是单独报告五种模型的结果，而是建立跨模型证据矩阵。

对于某一候选因素 \(f\)，综合考虑：

$$
Evidence(f)
=
\{
Effect,\ Attribution,\ Statistical\ Evidence,\ Stability,\ Context
\}
$$

并进一步记录：

* applicable models；
* supporting models；
* direction concordance；
* cell-line consistency；
* confidence interval；
* statistical evidence；
* attribution robustness。

最终将因素划分为：

### Strong convergent evidence

至少有多个适用模型支持，且方向一致，并有较强的统计或稳定性证据。

### Moderate convergent evidence

多个方法支持，但统计/稳定性证据尚不充分。

### Model-specific / exploratory evidence

主要由单个模型提供支持。

### Inconclusive

效应不稳定、方向冲突或不确定性较大。

### No current evidence

当前数据中没有得到稳定支持。

这里特别需要强调：

> **“No current evidence”不等于“无效应”。**

# 12 统计分析框架

平台将统计工具分为：

| 方法                      | 主要用途         |
| ----------------------- | ------------ |
| ΔR²                     | 增量预测贡献       |
| Bootstrap CI            | 效应不确定性与稳定性   |
| Paired bootstrap        | 配对增量效应       |
| Permutation test        | 零假设下的效应检验    |
| BH-FDR                  | 多重假设校正       |
| Factorial ANOVA         | 环境因素主效应与交互效应 |
| Motif enrichment        | motif 富集统计证据 |
| Cross-model concordance | 模型间一致性       |
| Cell-line consistency   | 跨细胞背景一致性     |

需要特别区分：

> **SNR 是归因稳健性指标，而不是传统假设检验的显著性指标。**

因此，对于 XGBoost、MLP、CNN 和 Transformer 的 attribution，不直接把原始 SNR 转换成 p-value 或 FDR。

# 21 讨论

## 21.1 多模型不是为了追求模型数量

本平台采用五种模型并非单纯进行模型 benchmark，而是利用不同数学归纳偏置获得互补证据。

Linear Regression 提供参数化主效应和经典统计解释；XGBoost 捕获树结构中的非线性关系；MLP 提供一般非线性特征组合基线；CNN 强调局部序列模式；Transformer 则提供跨位置信息交互视角。

因此，当多个性质不同的模型对同一候选因素产生方向一致的证据时，其结果比单一模型 attribution 更适合作为进一步研究的候选依据。

---

## 21.2 从预测走向科学发现

本平台的主要目标不是提出另一个单独的编辑效率预测模型，而是把预测模型转变成：

> **科研人员已有实验数据的“因素发现工具”。**

与仅输出一个编辑效率预测值相比，平台进一步回答：

```text
预测到了什么？
为什么这么预测？
哪些因素提供了增量信息？
这些因素是否稳定？
不同模型是否一致？
不同细胞环境是否一致？
哪些结果值得做下一步实验？
```

---

## 21.3 可解释性不等于因果性

需要特别强调：

$$
Prediction\ Evidence
\neq
Causal\ Evidence
$$

即使一个环境因素具有正的 \(\Delta R^2\)，或者一个 motif 被多个模型识别，也不能单独证明该因素对编辑效率具有因果作用。

同样，SHAP、IG 或 ISM 所表示的是模型层面的归因或反事实预测变化，并不能自动等价于真实生物机制。

因此，本平台的输出定位于：

> **candidate factor discovery and testable hypothesis generation**

而不是因果机制的最终证明。

# 22 局限性

## 22.1 案例数据限制

当前论文主要使用 DeepCRISPR 数据展示平台工作流程，因此其结论首先代表对该数据集的计算分析，而不能直接推广到所有编辑系统。

## 22.2 表观遗传信息依赖

环境因素分析依赖输入数据中环境变量的覆盖范围和测量质量。环境信息缺失、不同实验条件以及测量来源差异均可能影响增量贡献估计。

## 22.3 Attribution 的解释边界

模型归因方法解释的是模型决策，而不一定等同于真实生物学机制。

## 22.4 Motif 需要实验验证

从 CNN/Transformer attribution 中获得的 motif 只能作为候选序列模式。即使获得统计 enrichment，也仍需要定点突变、编辑实验或其他实验方法验证。

## 22.5 Cell-line context 与机制不能直接等同

不同 cell line 之间的效应差异说明存在 context dependence，但不能直接据此断言其对应不同分子机制。

## 22.6 多类基因编辑系统的扩展仍需验证

平台在架构上可以扩展到不同基因编辑系统，但不同编辑系统具有不同的 sequence grammar、PAM 规则、目标表型和实验体系，因此需要通过独立数据集进行验证。

# 23 结论

本研究建立了一个面向基因编辑系统的细胞环境感知型影响因素发现平台。平台以科研人员已有实验数据为入口，将数据质量控制、特征工程、受控机器学习实验、多模型可解释分析、环境因素分析、序列 motif discovery、cell-line context analysis 和跨模型证据整合组织为统一计算流程。

与单纯以预测精度为目标的模型相比，本平台进一步关注：

$$
\text{Measured Data}
\rightarrow
\text{Prediction}
\rightarrow
\text{Attribution}
\rightarrow
\text{Statistical Evidence}
\rightarrow
\text{Context}
\rightarrow
\text{Evidence}
\rightarrow
\text{Hypothesis}
$$

其核心目的不是将机器学习模型输出直接解释为生物学因果关系，而是从复杂实验数据中筛选具有多来源证据支持的候选因素，并将其组织成可以进一步实验验证的科学假设。

DeepCRISPR 数据在本文中作为平台案例，用于展示该分析框架从数据输入、模型训练到影响因素发现的完整运行过程。未来，该平台可以进一步扩展环境特征、编辑系统类型、全基因组候选设计及实验验证接口，从而形成面向多类核酸工具的智能设计与科学发现工作流。

**[8] Trabelsi A, et al.** Comprehensive evaluation of deep learning architectures for prediction of DNA/RNA sequence binding specificities. *Bioinformatics*. 2019;35:i269–i278. 这项研究系统比较了不同深度架构，并讨论了复杂架构、预测性能与可解释性的权衡，对你“五种模型作为互补数学视角”的论证很有用。([PubMed][7])

## 一个很重要的写作建议

你这篇论文现在**不要急着把所有你已经做过的代码细节全部塞进正文**。最好的组织方式是：

```text
正文
│
├── 为什么要做这个平台
├── 平台解决什么科学问题
├── 平台的方法学
├── 平台的软件架构
└── DeepCRISPR 案例证明平台能做什么
```

而：

```text
具体参数
完整实验矩阵
所有 1344 个实验
所有 CSV 字段
函数实现
全部超参数
全部 QC 规则
全部 Evidence rule
```

放到：

> **Supplementary Methods / Supplementary Tables / Code Availability**

这样正文才能真正像一篇方法学论文，而不是项目开发说明书。

另外，你现在**最需要补的不是“再找更多模型”**，而是把最终结果章节对应的数据补齐：尤其是 **环境效应 + Bootstrap/统计检验、CNN/Transformer motif、cell-line heterogeneity、Evidence Matrix**。这些一旦有了，你这篇文章的“Results”部分就能真正建立起来。
